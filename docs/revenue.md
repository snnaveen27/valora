## 13. Risk Mitigation

### 13.1 Key Risks & Mitigation

**Risk 1: Data Quality & Freshness**
```
Risk: Stale or incorrect data → poor predictions → user churn
Impact: High (core value prop)

Mitigation:
- Multiple data sources (reduce single point of failure)
- Automated quality checks (flag outliers)
- User feedback loop (let users report errors)
- Partnerships with authoritative sources
- Truth Firewall (verify all claims)

Monitoring:
- Verification pass rate >90%
- Data freshness <7 days
- User-reported errors <1%
```

**Risk 2: AI Hallucinations**
```
Risk: LLM generates false information → user makes bad decision → reputation damage
Impact: Critical (trust-based business)

Mitigation:
- Truth Firewall (architectural solution)
- Grounded-only claims (all numbers from deterministic agents)
- Confidence scores (show uncertainty)
- Human review for enterprise deals
- Insurance policy for errors (peace of mind)

Monitoring:
- Hallucination rate <0.1%
- Claims verified: >95%
- Customer complaints: <0.5%
```

**Risk 3: Regulatory Changes**
```
Risk: Government regulates AI in PropTech, data licensing, etc.
Impact: Medium (business model risk)

Mitigation:
- Proactive compliance (stay ahead of regulations)
- Legal counsel (PropTech specialist)
- Industry association membership (shape policy)
- Pivot capability (platform approach)

Monitoring:
- Quarterly legal review
- Track policy discussions
- Maintain relationships with regulators
```

**Risk 4: Competition from Well-Funded Players**
```
Risk: Magicbricks, 99acres build similar AI features
Impact: Medium (market share risk)

Mitigation:
- Build moats (data, brand, technology)
- Speed of execution (out-innovate)
- Lock in customers (switching costs)
- Partner where possible (embed our intelligence)

Monitoring:
- Competitive intelligence (track their products)
- Win/loss analysis (why customers choose us)
- NPS >60 (strong brand loyalty)
```

**Risk 5: Customer Concentration**
```
Risk: Top 10 customers = >50% revenue → if one churns, big impact
Impact: High (revenue volatility)

Mitigation:
- Diversify revenue across segments
- No customer >10% of revenue (guideline)
- Strong customer success (prevent churn)
- Expansion within accounts (reduce logo dependency)

Monitoring:
- Revenue concentration (top 10)
- Customer health scores
- Proactive renewals (start 90 days before)
```

**Risk 6: Technology Dependency**
```
Risk: Ollama/OpenRouter changes pricing/access
Impact: Medium (cost structure risk)

Mitigation:
- Multi-provider strategy (Ollama + OpenRouter + self-hosted)
- Local-first architecture (reduce cloud dependency)
- Model portability (can switch models)

Monitoring:
- Provider pricing changes
- Cost per query trending
- Diversification ratio (local vs cloud usage)
```
