# Residential Properties

This folder contains residential property data.

## Sub-categories:
- **flat**: Apartments and flats
- **house**: Independent houses
- **villa**: Luxury villas
- **plot**: Residential plots
- **1bhk**: 1 Bedroom properties
- **2bhk**: 2 Bedroom properties
- **3bhk**: 3 Bedroom properties
- **4bhk**: 4 Bedroom properties
- **5bhk**: 5 Bedroom properties
- **5plus-bhk**: 5+ Bedroom properties

## Expected columns:
name, description, price, area_sqft, location, latitude, longitude, city, locality, built_year, parking_spaces, balconies, floor, total_floors, age_years, transaction_type, price_per_sqft, listed_date, days_on_market
