# Commercial Properties

This folder contains commercial property data.

## Sub-categories:
- **office-space**: Office spaces and business centers
- **shop-showroom**: Retail shops and showrooms
- **commercial-land**: Commercial plots and land
- **warehouse-godown**: Storage and warehouse facilities
- **industrial-building**: Industrial buildings
- **industrial-shed**: Industrial sheds

## Expected columns:
name, description, price, area_sqft, location, latitude, longitude, city, locality, built_year, parking_spaces, balconies, floor, total_floors, age_years, transaction_type, price_per_sqft, listed_date, days_on_market
